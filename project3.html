Finance Calculator

Project 3

A web page built for use as a finance calculator, with appropriate formulas built in for ease of use. Contains a random question generator as well as a "smart input" text box.

A hackathon project, built for use as a calculator for finance or management subjects where it may seem tricky figuring out which formula to use. Therefore, a "smart input" section was built for aid, in which the user can input any values the question gives and the web page figures out which formulas will be applicable and the given answers.

This project introduced me to HTML and Javascript code, as well as basic design features.
